4. INSTRUCTIONS FOR OWNER
================================================================================

1. Render Backend Branch Configuration:
   - Go to Render Dashboard (dashboard.render.com).
   - Select the CCOE backend web service.
   - Go to Settings -> Build & Deploy -> Branch.
   - Change branch from 'deploy' to 'main'.
   - Verify Environment Variables before deploying:
     - GROQ_API_KEY (valid key required for fast suggestions)
     - GEMINI_API_KEY (valid key required for failover suggestions and chat)
     - MONGODB_DB (ensure it is NOT pointing to any test database)
     - Auto-Deploy: set as desired.

2. Deployment Order Warning:
   - Pushing main triggers an automatic frontend build on Vercel.
   - If Vercel finishes while Render still runs the old backend code (from 'deploy'),
     routes such as /api/suggest and /api/me will return 404 until Render is switched to 'main'.
   - Switch Render to 'main' promptly to keep frontend and backend in sync.

3. Run Vector Rebuild via GitHub Actions:
   - On GitHub, go to Actions -> "Daily KB Sync – charusat.online".
   - Click "Run workflow".
   - Set "Force rebuild vector DB" to true.
   - Run the workflow.
   - After completion, verify:
     a) A commit on main by github-actions[bot].
     b) Updated backend/last_sync.json.
     c) Refreshed backend/vector_db directory.
