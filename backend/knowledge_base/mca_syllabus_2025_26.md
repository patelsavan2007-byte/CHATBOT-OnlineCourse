# Online MCA Syllabus 2025-26 - CHARUSAT

## Program Overview

**Master of Computer Applications (MCA)** - 2-year online postgraduate program

### Key Program Details
- **Duration**: 2 years (4 semesters)
- **Total Credits**: To be completed as per course structure
- **Mode**: 100% Online
- **Maximum Duration**: 3 years (6 semesters)
- **Level**: Postgraduate

## Academic Structure

### 1. Semester System
- Each semester: Minimum 90 working days
- Designed for working professionals
- Project/dissertation included

### 2. Eligibility & Admission
- Eligibility criteria determined by CHARUSAT
- Mode of admission as per university regulations
- BCA or equivalent degree required

### 3. Credit System
- Choice Based Credit System (CBCS)
- Flexible course selection
- Credit-based progression

## Course Evaluation System

### Internal Evaluation (30%)
- Continuous assessment by faculty
- Includes assignments, presentations, projects

### Final Examination (70%)
- University-conducted online examinations
- Formats: Online tests, Practical, Oral, Presentation
- Combination of assessment methods allowed

### Passing Requirements
- Minimum passing marks: 36%
- Must obtain grade other than FF
- Relative grading system applied

## Grading System

### Grade Points
| Marks Range (%) | Letter Grade | Description | Grade Point |
|----------------|-------------|-------------|------------|
| 96.0 – 100     | O           | Outstanding | 10         |
| 86.0 – 95.9    | A+          | Excellent   | 9          |
| 76.0 – 85.9    | A           | Very Good   | 8          |
| 66.0 – 75.9    | B+          | Good        | 7          |
| 56.0 – 65.9    | B           | Above Average | 6       |
| 46.0 – 55.9    | C           | Average     | 5          |
| 36.0 – 45.9    | P           | Pass        | 4          |
| Below 36.0     | F           | Fail        | 0          |
| Absent         | Ab          | Absent      | 0          |

### Performance Calculation
- **SGPA** (Semester Grade Point Average): Σ(Ci × Gi) / ΣCi
- **CGPA** (Cumulative GPA): Average across all semesters
- Where Ci = course credits, Gi = grade point

## Degree Award Criteria

### Requirements for Degree Award
1. Complete all prescribed courses
2. Earn minimum required credits
3. Clear all evaluation components
4. Maintain minimum CGPA

### Class Award Criteria
| Class          | CGPA Range     |
|----------------|----------------|
| **Distinction** | ≥ 7.0 and ≤ 10.0 |
| **First Class** | ≥ 6.0 and < 7.0  |
| **Second Class**| ≥ 5.0 and < 6.0  |
| **Pass Class**  | ≥ 3.60 and < 5.0 |
