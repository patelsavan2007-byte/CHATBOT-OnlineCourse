# Online BCA Syllabus 2025-26 - CHARUSAT

## Program Overview

**Bachelor of Computer Applications (BCA)** - 3-year online undergraduate program

### Key Program Details
- **Duration**: 3 years (6 semesters)
- **Total Credits**: 145 credits
- **Mode**: 100% Online
- **Annual Fee**: ₹50,000 INR
- **Maximum Duration**: 5 years (10 semesters)

## Academic Structure

### 1. Semester System
- Each semester: Minimum 90 working days
- Course load specified per specialization
- Project/dissertation included where applicable

### 2. Eligibility & Admission
- Eligibility criteria set by CHARUSAT admission committee
- Based on Government of Gujarat regulations

### 3. Credit System
- Choice Based Credit System (CBCS)
- Students earn credits as per course structure
- Minimum required credits: 145

## Course Evaluation System

### Internal Evaluation (30%)
- Continuous assessment by course faculty
- Includes assignments, quizzes, projects

### Final Examination (70%)
- University-conducted examination
- Formats: Written, Practical, Oral, Presentation, or combination

### Passing Requirements
- Minimum passing marks: 36%
- Must obtain grade other than FF
- Relative grading system applied

## Grading System

### Grade Points
| Marks Range (%) | Letter Grade | Description | Grade Point |
|----------------|-------------|-------------|------------|
| 96.0 – 100     | O           | Outstanding | 10         |
| 86.0 – 95.9    | A+          | Excellent   | 9          |
| 76.0 – 85.9    | A           | Very Good   | 8          |
| 66.0 – 75.9    | B+          | Good        | 7          |
| 56.0 – 65.9    | B           | Above Average | 6       |
| 46.0 – 55.9    | C           | Average     | 5          |
| 36.0 – 45.9    | P           | Pass        | 4          |
| Below 36.0     | F           | Fail        | 0          |
| Absent         | Ab          | Absent      | 0          |

### Performance Calculation
- **SGPA** (Semester Grade Point Average): Σ(Ci × Gi) / ΣCi
- **CGPA** (Cumulative GPA): Average across all semesters
- Where Ci = course credits, Gi = grade point

## Class Award Criteria

| Class          | CGPA Range     |
|----------------|----------------|
| **Distinction** | ≥ 7.0 and ≤ 10.0 |
| **First Class** | ≥ 6.0 and < 7.0  |
| **Second Class**| ≥ 5.0 and < 6.0  |
| **Pass Class**  | ≥ 3.60 and < 5.0 |

## Course Types (CBCS)

### 1. Foundation Courses
- Prepare students for higher-level courses
- Build essential computer application skills

### 2. Core Courses
**A. University Core Courses (UC)**
- Compulsory across university
- Meet general program requirements

**B. Programme Core Courses (PC)**
- Specific to BCA program
- Essential computer science subjects

### 3. Elective Courses
**A. University Elective Courses (UE)**
- Pool of courses across all faculties
- Interdisciplinary learning opportunities

**B. Institute Elective Courses (IE)**
- Open to all university students
- Skill development courses

**C. Programme Elective Courses (PE)**
- BCA-specific electives
- Specialization options

## Program Objectives

### Vision
To become a leading institution in computer applications and contribute to national computerization efforts.

### Mission
To produce competent computer professionals equipped to face future challenges.

### Program Educational Objectives (PEOs)
1. Develop strong foundation in computer applications
2. Foster problem-solving and analytical skills
3. Prepare for industry requirements and career advancement

## Important Regulations

### Attendance Policy
- All prescribed activities are compulsory
- Exemption only for serious illness/accident/family emergency
- Absence requires Dean/Principal approval

### Detention Rule
- Promotion to next year requires clearing all current year courses
- Must earn minimum required credits
- Must clear all evaluation components

### Transcript
- Issued upon program completion
- Contains complete academic record
- Includes courses, credits, grades, SGPA, CGPA, class
