# Online MCA (Master of Computer Applications) - Complete Guide

## Overview

The online Master of Computer Applications (MCA) programme at CHARUSAT is designed to provide advanced learning opportunities to professionals, entrepreneurs, and learners in remote regions. It offers flexible, technology-assisted education without requiring physical attendance.

### Program Details

| Aspect | Details |
|--------|---------|
| **Duration** | 2 years (4 semesters) |
| **Total Credits** | 108 |
| **Annual Fee** | ₹75,000 INR |
| **Intake (2024-25)** | 1,000 students |
| **Mode** | 100% Online |
| **Delivery** | Asynchronous (flexible timing) |

## Eligibility Criteria

To be eligible for admission to the Online MCA programme, candidates must meet the following requirements:

- **Educational Qualification:** Bachelor's degree (or equivalent) in any stream

### Required Documents for Admission

**Identity & Address Proof:**

- Class 10 marksheet

- Any additional qualifications (if applicable)

## Curriculum & Course Structure

### Semester I

**Core Subjects:**
- Cloud Computing
- Web Development using Open Source Technologies
- Enterprise Computing using Java EE
- Programming with .NET Architecture
- Database Technologies
- Academic Speaking and Presentation Skills

### Semester II

**Core Subjects:**
- Programming in Python
- Advanced Web Designing
- Advanced Mobile Programming
- Software Engineering with Agile and DevOps
- Academic Writing

### Semester III

**Core Subjects:**
- Data Analytics
- Software Quality Assurance
- Green Computing
- Minor Project Work

### Semester IV

**Capstone Work:**
- Dissertation / Project Work – Industrial Training

**Focus:** Real-world application of learned concepts through an industrial project or dissertation.

## Examinations & Assessment

### Examination Format

**Examination Mode:**
- **100% Online:** No physical center visits required
- **Flexible Scheduling:** You can select appropriate exam dates from the university's provided schedule

### Examination Structure

**Question Types:**
- Multiple Choice Questions (MCQ)
- Descriptive/Long-answer questions
- Combination of both question types

**Features During Exam:**
- Can skip questions and return to them later
- Time management tools provided
- Secure browser environment
- Real-time proctoring verification

### Evaluation & Grading

**Assessment Breakdown:**
- **Internal Evaluation:** 30% of marks
  - Continuous assessment by course faculty
  - Based on assignments, quizzes, participation
- **University Examination:** 70% of marks
  - Conducted by the university

**Grading System:**
- Uses CBCS (Choice Based Credit System)
- **SGPA:** Semester Grade Point Average (per semester)
- **CGPA:** Cumulative Grade Point Average (across all semesters)
- **Minimum Passing:** 36% marks required to pass a course
- **Relative Grading:** Performance assessed on relative grading system

### Assignment Submission

**Submission Process:**
- Log into the Learning Management System (LMS)
- Navigate to the e-assignment module for each course
- Submit within the specified deadline

**Features:**
- Automatic date/time tracking of submissions
- Feedback system for assignments
- View grades and faculty comments
- Access submission history

**Q: What is the aim of the MCA Programme at CHARUSAT?**

A: The MCA Programme aims to provide sound knowledge of computer applications and equip learners with necessary skills to excel in the IT industry. The curriculum is designed to provide software skills and industry exposure through project-driven courses and hands-on experience.

**Q: What is the eligibility requirement for the Online MCA programme?**

A: Candidates must have a Bachelor's degree (or equivalent) in any stream with English as a subject or medium of instruction.

A: Required documents include:
