# CHARUSAT Online Examination - Complete Guide

## Overview

CHARUSAT conducts all online examinations using the **LM Exam Suite** software by Littlemore Innovation Labs. Examinations are **100% online with remote proctoring**, allowing students to take exams from home using their own devices.

---

## Examination Software: LM Exam Suite

**Software Details:**
- **Name:** LM Exam Suite
- **Developer:** Littlemore Innovation Labs Pte. Ltd. (Singapore)
- **Indian Operations:** Ppyrus India Pvt. Ltd.
- **Supported Platforms:** Windows (primary), macOS, Linux

---

## System Requirements

### Minimum Hardware Requirements

**Computer/Laptop:**
- Processor: Intel Core i3 or equivalent (minimum)
- RAM: 4GB minimum (8GB recommended)
- Webcam: Built-in or external USB camera (HD recommended)
- Microphone: Built-in or external microphone
- Speakers: For audio announcements

**Internet Connection:**
- Minimum Speed: 2 Mbps download
- Recommended: 5+ Mbps for stable connection
- Backup internet connection recommended

**Operating System:**
- Windows 10 or Windows 11
- macOS 10.14 or later
- Ubuntu or other Linux distributions

### Pre-Examination Setup

**Before Exam Day:**
1. Test your internet speed and stability
2. Ensure webcam and microphone work properly
3. Install/update LM Exam Suite software
4. Have all required documents ready
6. Close unnecessary programs and browser tabs
7. Disable VPN and proxy applications
8. Allow pop-ups from LM Exam Suite in your browser

## Step-by-Step Examination Process

### Step 1: Download LM Exam Software

**Where to Get:**
- Link provided by CHARUSAT Examination Cell
- Available in your LMS under "Examinations" section
- Download link sent via email before exam date

**Download Instructions:**
- Download the installer for your operating system
- Save to a known location (Desktop/Downloads)
- Do NOT run from email attachment

### Step 2: Install the Software

**Installation Process:**
1. Run the downloaded installer file
2. Follow on-screen installation prompts
3. Accept Terms & Conditions
5. Complete installation
6. Installer will create desktop shortcut

**Installation Tips:**
- Run as Administrator (Windows)
- Allow 5-10 minutes for complete installation
- Do not interrupt installation process
- Restart computer after installation (if prompted)

### Step 3: Launch LM Exam Software

**Opening the Application:**
1. Double-click the LM Exam Suite icon on desktop
2. Or find it in Start Menu (Windows) / Applications (Mac)
3. Wait for application to fully load
4. You will see the Login screen

### Step 4: Enter Login Credentials

**Login Information:**
- **Student ID / Roll No.:** Your university-provided student ID
  - Format: e.g., 2024-BCA-001 or 2024-001
  - Available in admission letter or LMS profile
- **Password:** Assigned password sent via email or SMS
  - Do NOT share your password

**Login Steps:**
1. Enter Student ID in first field
2. Enter password in second field
3. Click **"Login"** button
4. Wait for system to verify credentials

**If Login Fails:**
- Check caps lock on keyboard
- Verify you're entering correct Student ID
- Contact LMS support: lms@charusat.ac.in

### Step 5: Profile Validation

**Verification Screen:**
After successful login, verify your details:
- **Student ID / Roll No.:** Verify correct ID
- **Institution:** Should show "Charotar University of Science and Technology"
- **Program:** Should match your enrolled program (BCA/MCA/BBA/MBA)
- **Mobile Number:** Verify for important communications
- **Age:** Auto-calculated from date of birth

**Acceptance:**
- Review all details carefully
- Check the **"I Agree to Terms & Conditions"** checkbox
- Read the Terms & Conditions if first time
- Click **"Proceed"** button

### Step 6: Device Registration (One-Time)

**Registration Popup:**
A dialog will appear: **"Device Registration – User not registered on this device. Do you want to register?"**

**Registration Process:**
1. Click **"Register"** button
2. System captures device information
3. Device gets registered in your account
4. This is a **ONE-TIME process only**
5. Same device will not ask again for registration

### Step 7: Dashboard

**Dashboard Components:**

**Student Information Panel:**
- Roll No. / Student ID
- Program (BCA/MCA/BBA/MBA)
- Registered Mobile Number
- Age

**Navigation Options:**
- **"Start Practice Exam"** – Access mock/practice tests
- **"My Calendar"** – View scheduled exam dates
- **"Exam History"** – View past exam records

**Exam History Table Columns:**
- Code (Subject code)
- Program (Your program)
- Subject (Subject name)
- Date & Time (Exam schedule)
- Attendance (Present/Absent status)
- Upload Status (Answer paper upload status)

### Step 8: Review Terms and Conditions

**Before Any Exam:**
- Read the full **Terms and Conditions** carefully
- Note any specific rules for your institution
- Ask questions if anything is unclear
- Accept terms by clicking confirmation

**Key Rules to Remember:**
- No unauthorized materials during exam
- No communication with others
- Webcam and microphone must remain ON
- Only one monitor permitted
- Exam environment must be quiet
- No phones or external devices visible

### Step 9: Settings (Optional)

**Access Settings:**
- Click the settings/gear icon in header bar
- Settings icon typically located top-right

**Available Options:**

**Theme Mode:**
- **Dark Mode:** Dark background, light text

**Accessibility Options:**
- **Right-to-Left Mode:** For left-handed users

**Reset Button:**

- Use if you made unwanted changes

### Step 10: Dashboard Tutorial (Optional)

**Learn Key Features:**

**Application Header Bar Elements:**
- Page title display
- Dark/Light mode toggle button
- Storage indicator (available disk space)
- Battery indicator (device battery status)
- Logout button

**Sidebar Navigation:**
- Dashboard

**Important to Know:**
- Logout properly after each session

### Step 11: Starting Your Exam

**Select Your Exam:**
1. From Dashboard, locate your exam in **"My Calendar"**
2. Click on your exam/subject name
3. Verify exam details:
   - Subject name
   - Date and time
   - Duration
   - Number of questions

**Before Clicking Start:**
- Ensure you're in a quiet environment
- Check webcam and microphone are working
- Close all other applications
- Put phone on silent/airplane mode

**Click "Start Exam":**
- System begins pre-exam checks
- Webcam and microphone testing starts

### Step 12: Microphone Detection

**Microphone Test Screen:**
- System will activate your microphone
- You'll see **"Mic Detection"** dialog
- Instructions: Speak a sentence so system can detect microphone

**What to Do:**
1. Click "Test Microphone" or "Record"
2. Speak clearly (e.g., "Hi, my microphone is active!")
3. System processes your voice
4. You'll see message: **"We can hear you"** if successful
5. Click **"Proceed"** to continue

**If Microphone Fails:**
- Check microphone is not muted
- Check volume is not on 0%
- Try testing again
- Use different microphone if available
- Contact support if persistent issue

### Step 13: Face Detection & Identity Verification

**Face Recognition Screen:**
- System will activate your webcam
- Instructions displayed: "Face Detection - Unlock Exam"
- Security popup shows **"Do's and Dont's"**

**Do's During Face Detection:**
✓ Ensure face is clearly visible on camera
✓ Face entire camera (look directly at webcam)
✓ Ensure adequate lighting on your face
✓ Keep your face within the frame
✓ Remain still while camera captures

**Dont's During Face Detection:**
✗ Don't wear sunglasses or dark glasses
✗ Don't cover face with objects
✗ Don't hide face partially
✗ Don't look away from camera
✗ Don't turn around or move excessively

**Verification Process:**
1. System captures your face
2. Face is compared with your ID photo
4. Proceed to next step

**If Face Not Recognized:**
- Remove glasses if applicable
- Ensure better lighting
- Look directly at camera
- Try face detection again
- Contact support if repeated failures

### Step 14: Environment Check

**Room Scan Instructions:**
- System may request you to scan your exam room
- Use webcam to show surroundings
- Show walls, desk, floor area

**Environment Requirements:**
- Quiet, distraction-free space
- Adequate lighting
- Minimal background noise
- No other persons visible
- No unauthorized materials visible
- Secure internet connection

### Step 15: Final Checks Before Exam Starts

**System Verification:**
- Microphone working ✓
- Webcam working ✓
- Face recognized ✓
- Environment verified ✓
- Internet stable ✓
- Browser compatible ✓

**Exam Rules Display:**
- Read final rules and regulations
- Accept exam conduct agreement
- Confirm you understand penalties for violations

### Step 17: Answering Questions

**For Multiple Choice Questions (MCQ):**
1. Read question carefully
2. Review all four options
3. Click the radio button next to your answer
4. Selected option will be highlighted
5. Move to next question or mark for review

**For Descriptive Questions:**
1. Read question and word limit
2. Click in text box
3. Type your answer
4. Use formatting options if available (bold, italic, etc.)
5. Save answer (auto-saves typically)

**For File Upload Questions:**
1. Read upload requirements
2. Click "Upload" or "Choose File"
3. Select file from your computer
4. File uploads and shows confirmation
5. Replace file if needed

**Changing Your Answer:**
1. Navigate back to the question
2. Click different option (MCQ)
3. Or modify text (descriptive)
4. Changes auto-save

### Step 18: Question Navigation

**Moving Between Questions:**

**Option 1: Sequential Navigation**
- Click **"Next"** button to move forward
- Click **"Previous"** button to go back
- Questions answered in order

**Option 2: Direct Jump**
- Click any question number in left panel
- Jump directly to that question
- Useful to skip and return later

**Option 3: Review Later**
- Click **"Mark for Review"** button
- Question marked with orange flag
- Complete all questions first
- Return to marked questions later

**Recommended Strategy:**
2. Mark difficult questions for review
3. Return to marked questions if time permits
4. Review answers before submission

**Available Tools (if permitted):**

**On-Screen Calculator:**

**Time Management Tips:**
- Allocate time per question (e.g., 1 min per MCQ, 5 min per descriptive)
- Don't spend too long on one question
- If stuck, mark and move on
- Use remaining time for review
- Watch timer as exam progresses

**Time Warnings:**

- 10 minutes remaining: Alert message
- 2 minutes remaining: Alert message

**Final Review Checklist:**

✓ Ensure you're in a quiet, private location
✓ Close all unnecessary applications before starting
✓ Have good, even lighting on your face
✓ Keep webcam and microphone ON throughout
✓ Wear normal, presentable clothing
✓ Ensure stable internet connection
✓ Use pen and paper for rough calculations only
✓ Manage time wisely
✓ Answer in the language specified
✓ Remain seated and visible in camera

## Troubleshooting & Technical Issues

### Common Issues and Solutions

**Issue: Cannot Login**
- **Solution:** Verify Student ID and password are correct
- Check CAPS LOCK is off
- Try resetting password if forgotten
- Contact: lms@charusat.ac.in

**Issue: Microphone Not Detected**
- **Solution:** Check microphone is not muted
- Verify volume is not zero
- Restart the software
- Test microphone in Windows/Mac settings
- Try different microphone if available

**Issue: Face Not Recognized**
- **Solution:** Ensure adequate lighting on face
- Remove glasses if possible
- Look directly at camera
- Try face detection again
- Ensure only your face is visible

**Issue: Internet Disconnected During Exam**
- **Solution:** Reconnect to internet immediately
- Software may resume automatically
- Contact exam support immediately
- Don't restart; wait for system to reconnect

**Issue: Webcam/Camera Not Working**
- Verify no other app is using camera
- Restart computer if necessary
- Use external camera if built-in fails
- Test camera in system settings first

**Issue: Exam Software Crashes**
- **Solution:** Relaunch software immediately
- Your answers may be auto-saved
- Contact exam helpline urgently
- Have application reference number ready
- Report incident with exact time

- Continue answering questions
- Contact support only if timer seems way off
